Официальный публичный репозиторий релизов, скомпилированных дистрибутивов и автоматических обновлений лаунчера Hower для DayZ Standalone.

Здесь размещаются проверенные портативные сборки, автономные установщики (NSIS для Windows, AppImage для Linux), манифесты версий и бинарные пакеты обновлений десктопного клиента.

## Основные возможности

* **Официальные релизные сборки**: Прямая загрузка протестированных бинарных файлов без необходимости локальной компиляции.
* **Автоматические обновления**: Интеграция с механизмом автообновления клиента Hower Launcher через GitHub Releases API.
* **Контрольные суммы и безопасность**: Публикация хэшей SHA-256 для верификации целостности скачиваемых пакетов.

## Загрузка и установка

1. Перейдите во вкладку [Releases](https://github.com/KreziBro/hower-releases/releases).
2. Выберите последнюю стабильную версию.
3. Скачайте инсталлятор `Hower-Launcher-Setup-x.x.x.exe` (или портативную версию `.zip`).
4. Запустите установщик и следуйте инструкциям на экране.
